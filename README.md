# Serhii.dev — portfolio

Personal portfolio of Serhii Andriievskyi, front-end engineer: home, about, projects with video
walkthroughs, articles and contacts on a single page. Live: https://serhii-dev.vercel.app

## Stack

Next.js 14 (App Router), React 18, TypeScript, Tailwind CSS 3, Radix UI, i18next. Languages live in
the URL: `/en` (default), `/ru`, `/ua`; texts are in `src/app/i18n/locales/<lng>/translations.json`.

## Run

```bash
yarn install
yarn dev
```

Open http://localhost:3000.
